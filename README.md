# Dream Cast TV — Kotlin

Неофициальный клиент Dream Cast для **Android TV и Google TV**: каталог аниме,
библиотека и просмотр серий с управлением пультом.

Версия исходников — **v0.9.3** на Kotlin и
Jetpack Compose / TV Material. Приложение и его сборка работают без Flutter.
Старые Dart/Flutter-исходники удалены; проект сборки находится в `native-android/`.
Минимальная версия Android — **6.0 (API 23)**.

## Установка и совместимость

Переход с 0.8.x и более ранних версий на 0.9.x требует чистой установки:
удалите старое приложение вместе с данными, затем установите новый APK без
восстановления резервной копии. Перенос данных не поддерживается.

Чтение старых настроек Flutter удалено. Если ранее вы обновились поверх старой
версии без удаления данных, также выполните чистую установку.

## Что нового в v0.9.3

- Единый APK для аппаратного декодирования и программного AV1 через dav1d.
  Недоступный для текущего видео аппаратный режим нельзя включить.
- Увеличена очередь кадров dav1d; качество «Авто» снижается при устойчивых
  пропусках кадров на слабых устройствах.
- Исправлен переход кнопкой «Вниз» из поиска к тайтлам после закрытия клавиатуры.
- Удалены LibVLC, Dart/Flutter и неиспользуемые экспериментальные рендереры.

Подробности — в [заметках к v0.9.3](RELEASE_NOTES_v0.9.3.md).

## Возможности

- Каталог с пагинацией, фильтрами по году и нескольким жанрам; поиск и история запросов.
- Карточки тайтлов с описанием, метаданными, списком серий и отметками просмотра.
- Библиотека со статусами «Смотрю», «Просмотрено», «Брошено» и «В планах».
- Расписание, подписки на новые серии и история уведомлений.
- Сохранение позиции и продолжение просмотра, в том числе после перезапуска приложения.
- Выбор доступного потока и качества, пауза, перемотка ±10 секунд и следующая серия.
- Автопереход к следующей серии с отсчётом 5 секунд и возможностью отмены.
- Локальный профиль, системная / светлая / тёмная тема, акцент и системные цвета.
- Настраиваемый срок хранения кэша, статистика и ручная очистка.

## Скачать и установить

Опубликованные версии доступны в [Releases](https://github.com/Arleckin75/dreamcast-tv/releases).

1. Откройте нужный выпуск и скачайте единый APK Dream Cast TV.
   Для v0.9.3 имя файла — `DreamCast-TV-v0.9.3-unified-release.apk`.
2. Если файл упакован в архив, распакуйте его.
3. Перенесите APK на телевизор и установите приложение.

При удалении приложения его локальные настройки, история и библиотека удаляются.

Верхняя навигация доступна во всех основных разделах. На главной последние
обновления представлены баннером: при фокусе на «Подробнее» стрелки влево/вправо

Фокус выделяется рамкой и плавным увеличением постера. Общий фон подстраивается
под цвета выбранной обложки на главной, включая баннер, в каталоге, результатах
поиска, библиотеке и карточке тайтла. Цвета меняются плавно; при недоступной
обложке используется фон выбранной темы.

Кнопка «Серии» открывает список в диалоге. В фильтре жанров можно выбрать
несколько пунктов; «Применить» и «Сбросить» находятся на панели справа.

## Декодирование видео

Используется один APK на базе Media3/ExoPlayer с dav1d. Режим выбирается
в настройках плеера и сохраняется:

| Режим | Поведение |
| --- | --- |
| **Авто** | Предпочитает подходящий аппаратный декодер. Для AV1 без аппаратной поддержки использует dav1d; при ошибке аппаратного видеодекодера пробует dav1d с сохранением позиции. |
| **Аппаратное** | Доступно только при наличии аппаратного декодера, поддерживающего параметры текущего видео. Системные программные кодеки сюда не относятся. |
| **Программное AV1 — dav1d** | Принудительно использует dav1d. Для других видеокодеков пункт недоступен. |

Оба пути используют одну логику качества, скорости, HLS/DASH, прогресса,
следующей серии и автоматического PiP. При переключении декодирования
сохраняются позиция, скорость и состояние паузы. Недоступные пункты видны
серым и не активируются пультом. Поддержка проверяется для параметров потока,
а не только по названию кодека. Для старых устройств с dav1d рекомендуется
720p; при «Авто» качества программное AV1 ограничивается 720p, если такой поток доступен.
При устойчивых пропусках кадров «Авто» снижает разрешение до следующего доступного
варианта. Ручной выбор качества сохраняется без такого снижения.
