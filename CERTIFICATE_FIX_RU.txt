Dream Cast TV v0.7.1 — исправление проверки сертификата

Содержимое ZIP: только .github/workflows/build-tv-release.yml

Изменение: шаг проверки подписи v0.7.0 / v0.7.1 распознаёт форматы
"Signer #1 certificate SHA-256 digest" и "V2 Signer: certificate SHA-256 digest".
Выводит SHA-256 старого APK и каждого нового APK. Не допускает
публикации при отсутствии сертификата, неоднозначном результате
или настоящем несовпадении.

В ZIP использована версия workflow с исправлением Gradle audit
(Gradle 8.14 через gradle/actions/setup-gradle@v4).

ПРИМЕНЕНИЕ:
1. Обновить локальную main через GitHub Desktop (Fetch/Pull).
2. Создать новую ветку fix/v071-cert-digest-check.
3. Распаковать ZIP в корень проекта, заменить только build-tv-release.yml.
4. Проверить diff, commit и push этой ветки.
5. Открыть Pull Request в защищённую main и объединить после проверки.
6. Запустить Build Dream Cast TV Release APK из main.

Подпись APK, ключи и окружение release-signing не меняются.
