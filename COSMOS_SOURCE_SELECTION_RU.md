# Cosmos: диагностика всех источников серии

В Debug-сборке перед запуском плеера проверяются все уникальные URL, уже полученные приложением для выбранной серии. Android Media3 определяет наличие совместимой видеодорожки; первый источник с поддерживаемым видео выбирается автоматически. Если таковых нет, остаётся исходный источник и журнал объясняет причину. Время проверки каждого источника ограничено 6 секундами (максимум 12 ссылок). В Release основной выбор не меняется.

ADB-фильтр: `DCTV_TRACKS|DCTV_DIAG`. Строки `source=N video mime=... supported=...` показывают наличие H.264, HEVC или AV1. Никакие URL целиком не логируются. Для переключения между источниками с разными озвучками следует использовать обычный выбор пользователя; автопоиск работает только внутри уже переданного набора `streams`.
