# v0.7 — синхронизация LibVLC с «Продолжить просмотр»

- `CosmosAv1PlayerActivity` возвращает позицию, длительность и признак завершения через результат Android Activity.
- `MainActivity` передаёт данные обратно по каналу `dream_cast/media3_probe`.
- Flutter сохраняет позицию и запись истории просмотра через `PlaybackRepository.saveWatchProgress`, то есть в штатную Drift-базу, используемую главным экраном.
- Сохранение позиции в Android SharedPreferences сохранено для совместимости с уже просмотренными сериями.
- Интеграция не затрагивает ExoPlayer, фиксированное качество LibVLC 720p и оформление.

## Проверка

1. Установить Debug APK поверх прежней версии без очистки данных.
2. Запустить серию на Cosmos, посмотреть 1–2 минуты и выйти кнопкой Back.
3. Вернуться на главный экран: в «Продолжить просмотр» должен появиться тайтл с позицией.
4. Открыть серию снова: воспроизведение должно восстановиться.
5. Проверить другой профиль и завершённую серию (в последнем случае элемент не должен оставаться в «Продолжить просмотр»).

Логи: `DCTV_PROGRESS` и `DCTV_DIAG`.
