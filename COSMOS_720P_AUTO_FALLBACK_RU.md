# Cosmos / Android TV: AV1 software fallback (Debug only)

- Если Media3 обнаруживает поддерживаемую видеодорожку, используется штатный ExoPlayer.
- Если все доступные видеоисточники не поддерживаются, Flutter запускает отдельный LibVLC Activity.
- LibVLC выбирает только AV1 720p из HLS master, проверяет EXT-X-MAP и сегменты .m4s/.mp4 и открывает direct media playlist.
- 480p, 1080p и управление качеством стрелками удалены.
- Сохраняются управление паузой и шаговой перемоткой, fullscreen, диагностические журналы.
- Если 720p fMP4 отсутствует, показывается сообщение об ошибке, без переключения на 480p или 1080p.
- Реализация fallback находится в src/debug; в Release используется существующее воспроизведение.
- Ограничения: отдельная Activity LibVLC пока не интегрирована в полноценное сохранение прогресса и основной UI плеера.

Теги ADB: DCTV_TRACKS, DCTV_QUALITY, DCTV_FMP4, DCTV_AV1, DCTV_LAYOUT.
