# Перенос v0.8.5 в main

> Исторический документ об удалённой отдельной software-сборке. Сейчас используется единый APK на Media3 + dav1d. Актуальные инструкции: [сборка](../BUILD_TV.md), [декодирование](MEDIA3_DAV1D_RU.md).

Версия приложения — `0.8.5+805001`. Описание выпуска находится в
[заметках к релизу](../RELEASE_NOTES_v0.8.5.md), порядок сборки и публикации —
в [инструкции выпуска](../RELEASE_SIGNING_RU.md).

## Слияние веток

Main объединена с develop для устранения конфликтов Pull Request.
При дальнейшем переносе обновите сведения об удалённых ветках и дождитесь
успешных проверок Pull Request из develop в main. Не используйте принудительный push.

Разрешены конфликты в шести файлах:

| Файл | Итоговое содержимое |
| --- | --- |
| `.github/workflows/build-tv-apk.yml` | Подготовленная версия develop: v0.8.5, обе сборки, сокращённый LibVLC, сборка Release только из main, проверка сертификата и заметки из файла |
| `.github/workflows/build-tv-release.yml` | Вызов основного workflow с передачей секретов и выбором публикации; флажок публикации включён по умолчанию |
| `README.md` | Краткая версия develop без скриншотов, с изменениями v0.8.5 и полными сведениями об авторстве и лицензии |
| `.gitignore` | Правила develop вместе с защитой `*.jks`, `*.keystore` и `**/key.properties` из main; они уже добавлены в подготовленную версию |
| `BUILD_TV.md` | Сохранена актуальная инструкция сборки v0.8.5 из develop вместо удаления в main |
| `RELEASE_SIGNING_RU.md` | Сохранена актуальная инструкция подписи и выпуска v0.8.5 из develop вместо удаления в main |

Исправление распознавания SHA-256 сертификата из main перенесено в основной
workflow. Оно принимает обычный вывод `Signer #1` и вариант `V2 Signer:`,
отклоняет отсутствующие и неоднозначные значения. Gradle wrapper теперь хранится
в develop, поэтому аудит использует `native-android/gradlew`.

При последующих изменениях повторите проверки на итоговой ревизии:

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter test test/software_player_test.dart test/features/releases/search_keyboard_test.dart --flavor softwareAv1
python -m unittest discover -s scripts/tests -p test_libvlc_tv.py -v
actionlint
git diff --check
```

Workflow Verify запускается для main и develop, включая Pull Request.
После слияния сначала соберите Release с `publish: false` и проверьте оба APK.
Для публикации запустите **Build Dream Cast TV Release APK** из main
с включённым флажком публикации (`publish: true`).

## Проверки на телевизорах

Поиск и управление системной клавиатурой на old ATV пока не подтверждены.
Проверить ввод с пульта, поиск, Back, очистку и повторное открытие поиска.
Для old ATV использовать 720p; hardware AV1 проверить на Google TV.
В обеих сборках проверить воспроизведение, паузу, качество, сохранение позиции,
ручной и автоматический переход к следующей серии, отмену перехода,
последнюю серию и обновление прежнего Release без потери данных.

Локальные тесты не подтверждают подпись готового Release APK и длительную
стабильность на телевизоре. Перенос в main и публикация при подготовке не выполнялись.
