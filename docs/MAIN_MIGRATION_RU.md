# Перенос v0.8.4 в main

Версия приложения — `0.8.4+804001`. Описание выпуска находится в
[заметках к релизу](../RELEASE_NOTES_v0.8.4.md), порядок сборки и публикации —
в [инструкции выпуска](../RELEASE_SIGNING_RU.md).

## Слияние веток

При подготовке локальные main и develop расходились. Перед слиянием обновите
сведения об удалённых ветках и сохраните подготовленные изменения в develop.
Откройте Pull Request из develop в main. Не заменяйте main принудительным push.

Предварительная проверка выявила конфликты в четырёх файлах:

| Файл | Итоговое содержимое |
| --- | --- |
| `.github/workflows/build-tv-apk.yml` | Подготовленная версия develop: v0.8.4, обе сборки, сокращённый LibVLC, сборка Release только из main, проверка сертификата и заметки из файла |
| `.github/workflows/build-tv-release.yml` | Короткий вызов основного workflow из develop, с `publish: false` |
| `README.md` | Краткая версия develop без скриншотов, с изменениями v0.8.4 и полными сведениями об авторстве и лицензии |
| `.gitignore` | Правила develop вместе с защитой `*.jks`, `*.keystore` и `**/key.properties` из main; они уже добавлены в подготовленную версию |

Исправление распознавания SHA-256 сертификата из main перенесено в основной
workflow. Оно принимает обычный вывод `Signer #1` и вариант `V2 Signer:`,
отклоняет отсутствующие и неоднозначные значения. Gradle wrapper теперь хранится
в develop, поэтому аудит использует `android/gradlew`.

После разрешения конфликтов повторите проверки на итоговой ревизии:

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter test test/software_player_test.dart test/features/releases/search_keyboard_test.dart --flavor softwareAv1
python -m unittest discover -s scripts/tests -p test_libvlc_tv.py -v
actionlint
git diff --check
```

Workflow Verify запускается для main и develop, включая Pull Request.
После слияния сначала соберите Release с `publish: false` и проверьте оба APK.
Публикация требует отдельного запуска с `publish: true`.

## Проверки на телевизорах

Поиск и управление системной клавиатурой на old ATV пока не подтверждены.
Проверить ввод с пульта, поиск, Back, очистку и повторное открытие поиска.
Для old ATV использовать 720p; hardware AV1 проверить на Google TV.
В обеих сборках проверить воспроизведение, паузу, качество, сохранение позиции,
ручной и автоматический переход к следующей серии, отмену перехода,
последнюю серию и обновление прежнего Release без потери данных.

Локальные тесты не подтверждают подпись готового Release APK и длительную
стабильность на телевизоре. Перенос в main и публикация при подготовке не выполнялись.
