# Поиск и системная клавиатура

> Исторический документ об удалённой отдельной software-сборке. Сейчас используется единый APK на Media3 + dav1d. Актуальные инструкции: [сборка](../BUILD_TV.md), [декодирование](MEDIA3_DAV1D_RU.md).

## Устройства и текущий статус

- **old ATV, Android TV 11:** software AV1. В обычном Flutter-поле Gboard открывается,
  но управление буквами с пульта не работает. Сбой возникает до открытия видео;
  очистка данных и проверка software APK от 1 ноября его не устранили.
- **Google TV Cast:** hardware AV1. По сообщению пользователя ввод работает.

Это разные устройства. Совпадение Dart-кода, движка Flutter и манифеста APK
не означает одинаковое поведение IME на old ATV и Google TV Cast.

## Реализация

В software AV1 используется **одно поле Android EditText**, встроенное в строку
поиска AppBar через Hybrid Composition. Оно заменяет Flutter TextField:
отдельного окна, дополнительной строки и встроенной клавиатуры нет.
Hardware AV1 сохраняет обычное поле Flutter.

Нативный класс `TvSearchField` и его регистрация находятся только в source set
`softwareAv1`. Запросы, история и результаты остаются общими. Текст синхронизируется
в обе стороны: системный ввод обновляет контроллер, а очистка и выбор запроса
из истории обновляют нативное поле.

В software стрелки и OK передаются Android без поглощения Flutter Shortcuts.
Back в поле закрывает IME, после чего вниз переводит фокус к результатам.
Действие поиска на клавиатуре отправляет запрос. Используется текущий системный
IME; настройки клавиатуры приложение не меняет.

Параметры редактора основаны на рабочем системном «Поиске» old ATV:
обычный текст, действие поиска, отключённое персонализированное обучение и
privateImeOptions Gboard `noDecoding` / `noMicrophoneKey`. Другие IME могут
игнорировать специфичные параметры Gboard.

## Проверка

На old ATV проверено по ADB: при открытии поиска поле EditText было без фокуса,
а Android обслуживал Flutter View без подключения для ввода. OK не менял это
состояние. После касания EditText получил фокус и подключение ввода; текст
появился в поле. Поэтому начальный фокус перенесён на кадр после создания
поверхности, нативная часть ожидает присоединения к окну, а OK из Flutter
явно активирует редактор. Контур поля виден и без фокуса.

Эта проверка выполнена на прежнем APK; новый код требует установки и повторной
проверки открытия поиска и OK на устройстве.

```sh
flutter test --no-pub test/features/releases/search_keyboard_test.dart
flutter test --no-pub test/features/releases/search_keyboard_test.dart --flavor softwareAv1
```

Тесты проверяют одно поле без Dialog, передачу стрелок, синхронизацию текста,
очистку и освобождение view. Они подменяют нативный канал и не проверяют Gboard.
Компиляция Kotlin также не является проверкой системной клавиатуры.

**Новый встроенный редактор пока не подтверждён на old ATV.** После пересборки
проверить стрелки и OK по буквам, поиск, Back, переход к результатам и возврат
вверх, очистку, историю и повторное открытие экрана. Аппаратный поиск проверить
на Google TV Cast отдельно.
