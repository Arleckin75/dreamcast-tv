# Системный ввод поиска на Cosmos

03.11.2026 воспроизведён дефект установленной software AV1 на Cosmos через ADB:
Gboard показан (`mInputShown=true`), но стрелка вниз с источником D-pad не меняет
выделение буквы `q`. На том же устройстве в системном приложении «Поиск» такое
же нажатие переместило выделение с `g` на `b`.

Обе программы используют выбранный системный IME
`com.google.android.inputmethod.latin/com.android.inputmethod.latin.LatinIME`
(Gboard). Отличаются параметры редактора и обработка событий ввода:

| Поле | Dreamcast до изменения | Системный поиск |
|---|---|---|
| inputType | `0x8001` | `0x1` |
| imeOptions | `0x2000003` | `0x8000003` |
| privateImeOptions | отсутствуют | `noDecoding`, `noMicrophoneKey` Gboard |

У плавающей клавиатуры видимые нижние отступы равны нулю, поэтому проверка только
Flutter viewInsets не подтверждает отсутствие IME. Предыдущие widget-тесты
проверяли запрос открытия, но не реальную навигацию по буквам Gboard.

Попытка использовать отдельный нативный EditText привела к двум видимым полям
ввода. По просьбе пользователя этот обход удалён полностью: класс TvSearchInput,
регистрация его канала, readOnly-режим исходного поля и дополнительная кнопка
открытия клавиатуры убраны.

Поиск для обеих сборок восстановлен побайтно из коммита `80a218f` от 02.11.2026,
до последних GUI-изменений. В GUI-коммите `7e7de5d` сам SearchScreen и параметры
ввода не менялись; оснований объявлять конкретное GUI-изменение причиной сбоя
пока нет. Оформление кнопок и изменения плееров сохранены.

Тесты обеих тем проверяют единственное редактируемое поле, штатный текстовый
ввод, повторное открытие по нажатию на поле, сохранение запроса и отсутствие
вызовов удалённого нативного канала. Они не проверяют реальную навигацию по буквам
Gboard. После пересборки требуется проверка прежнего пути на Cosmos: отсутствие
двойного поля, стрелки и OK в Gboard, ввод и переход к результатам. Первоначальный
сбой управления клавиатурой не объявляется исправленным без этой проверки.

Снимки сравнения сохранены локально в `.tools/search-ime-*.png` и
`.tools/native-search-*.png`, в Git не входят.
