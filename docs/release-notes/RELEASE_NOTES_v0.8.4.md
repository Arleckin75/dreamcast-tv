# Что нового в v0.8.4

Изменения после v0.7.1:

- Плееры software AV1 и hardware AV1 теперь оформлены одинаково. Управлять просмотром с пульта стало удобнее: доступны выбор качества и переход к следующей серии.
- Плеер показывает загрузку и сообщения об ошибках. При ошибке можно повторить воспроизведение.
- После окончания серии запускается обратный отсчёт до следующей. Переход можно отменить или вернуться к тайтлу. На последней серии отсчёта нет.
- Исправлено сохранение позиции просмотра при смене качества, выходе из плеера и переходе между сериями.
- Кнопки во всём приложении получили единый контурный стиль и заметное выделение при управлении пультом.
- Доработана загрузка каталога и сохранение уже загруженных данных.
- Облегчена сборка software AV1. Убрано скачивание серий.

## Какую сборку выбрать

- **software AV1** — для old ATV и устройств без аппаратной поддержки AV1. Для old ATV используйте 720p.
- **hardware AV1** — для Android TV и Google TV с аппаратной поддержкой AV1.

Установите один вариант: одновременно использовать обе сборки нельзя.
К APK приложены файлы SHA-256 для проверки загрузки.

## Что ещё проверяется

Поиск и управление системной клавиатурой на old ATV пока не подтверждены на устройстве. Длительная стабильность воспроизведения также требует проверки на телевизорах.
