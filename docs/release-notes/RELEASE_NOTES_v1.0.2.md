# Dream Cast TV v1.0.2 — готовится

Единый нативный APK для Android TV и Google TV на Kotlin и Jetpack Compose.
Следующая версия — `1.0.2`, Android versionCode — `1002001`. Поддерживаются
ARMv7 и ARM64, минимальная версия Android — 6.0 (API 23).

## Плеер

- **Пауза сохраняется при смене декодера.** Если видео было на паузе,
  после выбора другого декодера оно остаётся на паузе с той же позиции.
  Переключение по-прежнему пересоздаёт экран плеера; аппаратное видео
  выводится через TextureView, как требуется для телевизоров вроде Candy.
- **Play/Pause работает во время буферизации.** Кнопка на экране и кнопка
  пульта переключают намерение воспроизведения, даже если плеер ещё ждёт
  данные и не показывает видео.
- **Тайм-аут проверки видеопотока показывает ошибку.** Через 20 секунд
  ожидания плеер предлагает повторить попытку вместо бесконечного
  индикатора «Проверка видеопотока…». Обычный выход из плеера отменяет
  проверку без сообщения об ошибке.

## Обновления

- **Отмена скачивания прерывает HTTP-запрос.** Ожидание ответа и чтение
  данных прекращаются при отмене загрузки; потоки закрываются, недокачанный
  APK удаляется.
- **Отмена проверки обновлений также прерывает запрос.** Это работает
  как до получения заголовков ответа, так и во время чтения данных.
  Отменённая автоматическая проверка не отмечается как успешная и может
  быть выполнена снова.

## Сеть

- **Клиент сайта не следует перенаправлениям.** Ответы с перенаправлением,
  включая переходы внутри сайта, обрабатываются как ошибка без повторных
  попыток. Ограничение относится к запросам страниц и каталога через
  SiteClient; загрузка видеопотоков и APK использует отдельные клиенты.

## Проверки

Локально прошли 196 модульных тестов, Debug и Release Lint без ошибок,
сборки Debug и Release с R8, а также сборка APK инструментальных тестов.
Проверены сохранение паузы, переключение Play/Pause до начала
воспроизведения, тайм-аут проверки потока, запрет перенаправлений и отмена
сетевых запросов обновления.

Инструментальные тесты на телевизорах для этих изменений не запускались.
