# Dream Cast TV v1.0.4

Единый нативный APK для Android TV и Google TV на Kotlin и Jetpack Compose.
Версия — `1.0.4`, Android versionCode — `1004001`. Поддерживаются
ARMv7 и ARM64, минимальная версия Android — 6.0 (API 23).

## СРОЧНОЕ ИСПРАВЛЕНИЕ

- **«Продолжить просмотр» снова открывает серии.** Нажатие на карточку
  открывало окно «Серии» с «Ошибкой сервера: 404». Сайт отдаёт страницу
  тайтла только по полному адресу с названием, например
  `/home/release/91-pererozhdenie-diadi-isekai-ojisan`. А приложение
  запоминало для просмотренных серий лишь номер тайтла и обращалось по
  короткому адресу `/home/release/91`. Пока страница тайтла лежала в кэше,
  ошибки не было видно; когда запись в кэше устаревала, появлялась ошибка.
- **Теперь вместе с позицией сохраняется полный адрес страницы.** Он
  хранится в новой колонке таблицы просмотров; в существующую базу колонка
  добавляется при первом запуске, остальные данные не меняются.
- **Карточки, сохранённые до обновления,** заработают, когда вы откроете
  тайтл из каталога, поиска или библиотеки и посмотрите любую серию: адрес
  запишется и подхватится всеми карточками этого тайтла.

## Установка и совместимость

Файл выпуска — `DreamCast-TV-v1.0.4-unified-release.apk`; рядом публикуется
контрольная сумма SHA-256. Версии 0.9.5–1.0.3 предложат обновиться сами.
Подпись та же, данные сохраняются. Переход с 0.8.x и более ранних версий
по-прежнему требует чистой установки.

## Проверки

Локально прошли 209 модульных тестов, Debug и Release Lint без ошибок,
сборки Debug и Release с R8. Новые тесты проверяют, что полный адрес
сохраняется и переживает перезапуск, что запись без адреса берёт адрес другой
серии того же тайтла и что база прежнего формата открывается без потери данных.

Причина ошибки проверена на сайте: короткий адрес тайтла отвечает 404,
полный — 200. На телевизорах исправление не проверялось.
