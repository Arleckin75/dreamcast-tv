# Dream Cast TV v0.9.3

Единый нативный APK для Android TV и Google TV на Kotlin и Jetpack Compose.
Версия — `0.9.3`, Android versionCode — `903001`. Поддерживаются ARMv7 и ARM64,
минимальная версия Android — 6.0 (API 23).

## Изменения

- Аппаратная и программная версии объединены на базе аппаратного плеера.
  Один APK содержит Media3/ExoPlayer и dav1d для программного декодирования AV1.
- В меню доступны «Авто», «Аппаратное» и «Программное AV1 — dav1d».
  Аппаратный режим недоступен, если устройство не поддерживает формат текущего
  видео. Выбор сохраняется; переключение сохраняет позицию и паузу.
- В «Авто» используется подходящий аппаратный декодер. При его отсутствии для
  AV1 выбирается dav1d; при ошибке аппаратного видеодекодера доступен однократный
  переход на dav1d с сохранением позиции.
- Очереди dav1d увеличены до 12 буферов. Качество «Авто» предпочитает видео до
  720p и снижает разрешение при устойчивых пропусках кадров. Ручное качество
  автоматически не понижается.
- Исправлена навигация пультом из строки поиска к результатам после закрытия
  системной клавиатуры. Стрелки при открытой клавиатуре остаются для ввода текста.
- Сохранены HLS/DASH, выбор качества и скорости, перемотка, история просмотра,
  переход к следующей серии и PiP.
- Лицензии Media3, dav1d, cpu_features и NDK доступны офлайн в разделе
  «О приложении». LibVLC и Dart/Flutter удалены из проекта и сборки.
- Удалены неиспользуемые GL-прототипы, экспериментальные тесты и предварительные
  отчёты. Релизный workflow собирает один APK из `main`.

## Установка и совместимость

Файл выпуска — `DreamCast-TV-v0.9.3-unified-release.apk`; рядом публикуется
контрольная сумма SHA-256.

Обновление с сохранением данных требует прежнего ключа подписи. Workflow
проверяет сертификат относительно v0.7.0 и увеличение versionCode. Удаление
приложения удаляет его локальные данные.

На Cosmos проверены программное AV1 720p, недоступность аппаратного режима,
поиск и открытие лицензий. На Google TV Streamer проверены аппаратный AV1,
переключение на dav1d, сохранение позиции и паузы, поиск и лицензии.
Полная проверка подписанного обновления с пользовательскими данными и всех
сценариев возврата из PiP ещё не завершена.
