# Dream Cast TV v1.0.7

Единый нативный APK для Android TV и Google TV на Kotlin и Jetpack Compose.
Версия — `1.0.7`, Android versionCode — `1007001`. Поддерживаются
ARMv7 и ARM64. **Минимальная версия Android — 9 (API 28)**; до v1.0.6
включительно — 6.0 (API 23).

## Совместимость

- **Нужен Android 9 или новее.** Текущие библиотеки Android (Compose,
  Lifecycle, WorkManager, OkHttp) больше не поддерживают старые версии, и без
  этого приложение не могло получать их обновления. На Android 6–8 последняя
  доступная версия — v1.0.6. Приложение там предложит обновиться, но установка
  новой версии не пройдёт; уже выпущенные версии исправить нельзя.
- **Файл выпуска больше: около 7 МБ вместо 5,4.** На Android 9 и новее код
  приложения лежит в APK несжатым: телевизор выполняет его прямо из файла и
  не хранит отдельную распакованную копию. Скачивать обновление чуть дольше,
  зато во внутренней памяти занято меньше, а установка и запуск быстрее.

## Сборка и библиотеки

- Android Gradle Plugin 9.5.2 со встроенным Kotlin, Gradle 9.9.2, Kotlin 2.4.21,
  сборка под API 37.1.
- Compose BOM 2026.11.01, Lifecycle 2.11.1, core-ktx 1.19.1, OkHttp 5.5.1,
  WorkManager 2.12.0, jsoup 1.24.1. Плеер Media3 1.11.1 и dav1d не менялись.
- Убраны обходы для Android ниже 9 и неиспользуемые PNG-иконки запуска.

## Просмотр

- **«Продолжить просмотр» запускает серию сразу**, без мелькания окна
  «Серии». Окно открывается, только если серию не удалось запустить, — чтобы
  выбрать другую, и только если главная ещё на экране.
- **Плеер всегда запускает открытый экран приложения.** Раньше, если система
  пересоздавала экран, пока серия готовилась к запуску, плеер мог не открыться.

## Внутри

- Окна выбора, «Настройки» и «Расписание» упрощены без изменения поведения;
  кнопки плеера рисуются без лишней работы на каждом кадре.

## Установка и совместимость

Файл выпуска — `DreamCast-TV-v1.0.7-unified-release.apk`; рядом публикуется
контрольная сумма SHA-256. Версии 0.9.5–1.0.6 на Android 9 и новее предложат
обновиться сами. Подпись та же, данные сохраняются. Переход с 0.8.x и более
ранних версий по-прежнему требует чистой установки.

## Проверки

Локально прошли 226 модульных тестов, Debug и Release Lint без ошибок,
сборки Debug и Release с R8; CI на `develop` прошёл.

Вручную, отладочной сборкой отдельным пакетом:
- Google TV Streamer (Android 14, аппаратный AV1): главная, тайтл, серии,
  просмотр, «Продолжить просмотр», «Настройки», запуск серии из списка, из
  «Продолжить просмотр» и с ручным выбором потока (DASH);
- Cosmos (Android 11, ARMv7): просмотр через dav1d в 720p и 1080p без
  пропущенных кадров, сохранение прогресса.

Release-сборка с R8 на телевизорах не запускалась. Chromecast не проверялся.
