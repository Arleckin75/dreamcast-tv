# Dream Cast TV v1.0.5

Единый нативный APK для Android TV и Google TV на Kotlin и Jetpack Compose.
Версия — `1.0.5`, Android versionCode — `1005001`. Поддерживаются
ARMv7 и ARM64, минимальная версия Android — 6.0 (API 23).

## Экран тайтла

- **Баннер и сведения у тайтлов из «Продолжить просмотр» и уведомлений.**
  Запись просмотра хранит только номер, название и адрес тайтла, поэтому у
  таких тайтлов не было баннера и строки «год • сезон • студия». Теперь
  приложение берёт со страницы тайтла оригинальное название, год, сезон,
  студию и жанры, если их нет.
- **Баннер не подменяется чужим.** Когда тайтл не находится на AniList по
  полному названию, приложение ищет по его началу. Раньше в этом случае мог
  подойти любой тайтл того же года; теперь — только тот, чьё название
  начинается так же.

## Продолжить просмотр

- **Старые карточки больше не дают «Ошибку сервера: 404».** Это более
  углублённое и подробное исправление v1.0.4. Если адрес тайтла устарел —
  запись сохранена до 1.0.4 с одним номером тайтла или сайт сменил адрес, —
  приложение находит тайтл через поиск каталога сайта, сверяет номер и
  открывает страницу по новому адресу. Настоящий адрес берётся со страницы и
  при следующем просмотре сохраняется в «Продолжить просмотр». Поиск идёт
  только к сайту Dream Cast.

## Настройки

- **«Очистить кэш?» — с кнопкой «Отмена».** Окно показывает «Отмена» (в
  фокусе) и «Очистить», как окно очистки истории уведомлений: одно лишнее
  нажатие OK больше не стирает кэш.
- **Очистка кэша сразу забывает найденные баннеры.** Раньше уже открытые
  тайтлы до перезапуска приложения брали баннер из памяти.

## Безопасность

- **Ссылки на тайтл от других приложений.** Из такой ссылки приложение берёт
  только номер, название и адрес тайтла. Обложка, оригинальное название и
  остальные сведения приходят со страницы сайта, поэтому чужое приложение не
  может подставить свою картинку или текст для запроса к AniList.

## Установка и совместимость

Файл выпуска — `DreamCast-TV-v1.0.5-unified-release.apk`; рядом публикуется
контрольная сумма SHA-256. Версии 0.9.5–1.0.4 предложат обновиться сами.
Подпись та же, данные сохраняются. Переход с 0.8.x и более ранних версий
по-прежнему требует чистой установки.

## Проверки

Локально прошли 216 модульных тестов, Debug и Release Lint без ошибок,
сборки Debug и Release с R8. Новые тесты проверяют разбор сведений и адреса со
страницы тайтла, отказ от адреса другого тайтла или чужого сайта, поиск адреса
после 404, склейку жанров, сохранение ошибки для тайтла, которого нет в каталоге, и выбор
баннера при поиске по началу названия.

Разбор страницы и ответ сайта проверены на настоящем сайте: короткий адрес
тайтла отвечает 404, полный — 200, на странице есть оригинальное название,
год, сезон, студия, жанры и `canonical` с полным адресом. На телевизорах
выпуск не проверялся.
