# Первый запуск software-плеера на Cosmos

> Исторический отчёт о прежнем LibVLC. Текущий software-плеер и его проверки описаны в [Media3 + dav1d](MEDIA3_DAV1D_RU.md).

Проверено 5 ноября 2026 года на Cosmos, Android 11, ARMv7. При первом
воспроизведении LibVLC запускал FreeType/Fontconfig и создавал базу системных
шрифтов даже у видео без отдельной дорожки субтитров. Этот этап занял 56,08 с.
Создание движка заняло 282 мс, начальное заполнение сетевого буфера — 5 мс.
Инициализация графического вывода начиналась уже после сканирования шрифтов.

В software-варианте добавлен параметр `--text-renderer=none`. По согласованию
с пользователем отдельные текстовые субтитры не нужны. Надписи, встроенные
в изображение видео, звук и элементы управления Android сохраняются.
Декодер, видеовывод и настройки буферизации не менялись.

## Измерения на устройстве

Источник — локальный MockWebServer и один и тот же тестовый AV1 720p HLS/fMP4.
Для каждой сборки использовался новый applicationId и первый запуск плеера,
чтобы прогретый кеш приложения не влиял на сравнение.
Измеряется время от запуска Activity до появления видеовывода и продвижения
позиции воспроизведения минимум на 100 мс.

| Сборка | До начала воспроизведения |
| --- | ---: |
| Исходная | 59 124 мс |
| Проверка отключения текстового рендерера | 3 237 мс |
| Итоговая, без экспериментальных переключателей | 3 426 мс |

Это измерение локального источника: загрузка реальной серии дополнительно
зависит от сети и сервера.

`SoftwareStartupTest` проверяет видеовывод, продвижение позиции и предел
10 секунд. Для воспроизведения именно холодного сценария его следует запускать
отдельным инструментальным процессом после установки с новым applicationId.
`SoftwarePlaybackTest` также прошёл на Cosmos: начало воспроизведения,
сохранение прогресса, пересоздание Surface при сворачивании, восстановление
видеовывода и продвижения позиции, выход кнопкой «Назад».

Диагностические замеры создания движка и запроса воспроизведения пишутся
с тегом `DCTV_STARTUP`. Расширенный вывод LibVLC доступен только в debug-сборке
с Intent-параметром `diagnosticVlcLogging=true`.

Дополнительные проверки: 95 software unit-тестов без ошибок, lint — 0 ошибок,
55 предупреждений и 5 hints. Debug и release APK собраны успешно;
аудит состава release APK — PASS (LibVLC/JNI сохранены, ExoPlayer отсутствует).
Временные тестовые приложения удалены, основное приложение и его данные
не изменялись.

Причина сверена с исходниками используемой ревизии VLC:
[создание текстового рендерера](https://github.com/videolan/vlc/blob/84177b2273abc5c4300234e6e18b55a4d2dd5a03/src/video_output/vout_subpictures.c),
[инициализация FreeType](https://github.com/videolan/vlc/blob/84177b2273abc5c4300234e6e18b55a4d2dd5a03/modules/text_renderer/freetype/freetype.c),
[создание базы Fontconfig](https://github.com/videolan/vlc/blob/84177b2273abc5c4300234e6e18b55a4d2dd5a03/modules/text_renderer/freetype/fonts/fontconfig.c).
