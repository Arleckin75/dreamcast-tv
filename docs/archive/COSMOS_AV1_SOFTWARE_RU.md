# Dream Cast TV v0.7 — AV1 software fallback (debug)

При выборе несовместимого видео на Android тестовая сборка запускает **LibVLC 3.7.7** с отключённым аппаратным декодированием. Это готовая библиотека с поддержкой программного AV1, а не нативное расширение Media3 dav1d; обычный Media3/ExoPlayer не менялся.

1. Устанавливается рядом со стабильной v0.6.0 благодаря `.diagnostic`.
2. Откройте AV1-серию: если все кандидаты несовместимы, появится полноэкранный LibVLC.
3. OK = пауза/воспроизведение; влево/вправо = -/+10 сек; Back = возврат.
4. `adb logcat -d -s DCTV_AV1:D DCTV_TRACKS:I` — журнал без URL.

## Ограничения теста

- Только Debug. Обычный player и стабильный Release остаются без изменений.
- Параметры `User-Agent` и `Referer` передаются LibVLC; произвольные HTTP-заголовки (например, Cookie/Authorization) не поддерживаются этим тестовым мостом.
- В LibVLC не интегрированы субтитры, управление выбором озвучки и сохранение прогресса при выходе. Позиция при запуске передаётся best-effort.
- LibVLC стремится выбрать низкое качество адаптивного потока; это не гарантия именно 480p.
- Успех зависит от производительности CPU Cosmos и характеристик AV1-потока.
- Не проводилась Android/Flutter компиляция в этой среде; проверить на GitHub Actions и Cosmos.
- Не заменяйте `main`. Требуется отдельная проверка LGPL требований LibVLC перед выпуском для широкой аудитории.
