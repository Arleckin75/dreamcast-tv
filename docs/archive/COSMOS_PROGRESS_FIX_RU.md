# Восстановление позиции LibVLC (Debug v0.7)

Для потоков без поддерживаемого декодера Android приложение открывает LibVLC 720p. Его экран является отдельной Activity, поэтому штатный таймер Flutter не сохранял прогресс.

Исправлено: LibVLC сохраняет положение серии с периодичностью около 3–6 секунд, а также при паузе/выходе. Ключ — пара ID релиза и эпизода. Следующий запуск той же серии восстанавливает позицию, когда поток становится доступен для перемотки. В конце серии сохранённая позиция удаляется. Логи `DCTV_PROGRESS`.

Ограничение: данные сохраняются в SharedPreferences диагностического Android-приложения. Это не общий Drift/SQLite каталог «Продолжить просмотр»; визуальный статус серии в интерфейсе Flutter может не обновиться. Для полноценной синхронизации в каталог потребуется отдельный мост Native → Flutter.

Схема AV1 720p fMP4, ExoPlayer, тёмная тема и остальной интерфейс без изменений.
