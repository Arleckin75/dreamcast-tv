# Тёмная тема по умолчанию

При первом запуске, когда `settings.theme_mode` отсутствует, используется `ThemeMode.dark`. Ранее сохранённые предпочтения пользователя (`system`, `light`, `dark`) сохраняют приоритет. Ручной выбор темы в настройках не изменён.

Изменение включено в диагностический `develop` с автоматическим резервным воспроизведением AV1 720p fMP4.
