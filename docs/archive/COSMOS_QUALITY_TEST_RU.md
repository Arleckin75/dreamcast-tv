# Cosmos: выбор качества AV1 fMP4 (Debug)

- По умолчанию открывается подтверждённый AV1 480p `.m4s`.
- `↑` — принудительно открыть отдельный HLS media playlist AV1 720p fMP4, если он существует.
- `↓` — вернуться на AV1 480p fMP4.
- Если нужный fMP4 вариант не найден, текущий плеер остаётся активным.
- Логи: `DCTV_QUALITY`, `DCTV_480P`, `DCTV_AV1`, `DCTV_LAYOUT`.
- Переключение пересоздаёт LibVLC; позиция и прогресс не сохраняются между режимами.
- Это диагностическая функция, не автоматический выбор оптимального качества.
- Интерфейс сериалов и релизная сборка не изменены.
