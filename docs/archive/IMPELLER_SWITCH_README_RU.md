# Impeller — тест Cosmos (ветка develop)

В **Настройки → Impeller (графический движок)** можно включать и выключать Impeller.

- Изначально **выключен** в диагностической сборке: Skia.
- Изменение записывается в Android SharedPreferences, а флаг передаётся при создании Flutter Engine.
- **Для применения нужно полностью закрыть приложение** (долгое нажатие Back) и запустить заново. Просто выход на главный экран ТВ не гарантирует пересоздания Engine.
- В ADB проверить: `adb logcat -d -s DCTV_RENDERER:I` (лог покажет `Impeller enabled=true/false`).
- Это переключатель **графического движка Flutter**, не аппаратного декодирования ExoPlayer.

Обратите внимание: новый Flutter может изменить поддержку отключения Impeller. Проверяйте по журналу и фактическому воспроизведению; переключатель не гарантирует устранения чёрного экрана.

Debug имеет отдельный applicationId `com.dreamcast.app.diagnostic`, Release v0.6.0 не заменяет. Изменения не прошли проверку компиляцией на CI.
