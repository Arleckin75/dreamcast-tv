# Что нового в v0.8.5

- Исправлена передача фокуса полю поиска software AV1 после появления на экране. OK явно активирует ввод, даже если фокус ещё остаётся на Flutter.
- Возвращён видимый контур поля поиска.
- В исходниках добавлена защита классов LibVLC от удаления и переименования при сборке Release. Установленная v0.8.5 завершалась при загрузке JNI из-за отсутствующего `IMedia$Track`; исправление требует новой сборки и проверки HLS на устройстве.
- Восстановлена публикация через **Build Dream Cast TV Release APK** из main. Публикация включена по умолчанию; флажок можно снять, чтобы получить только подписанные APK.
- Тестовая сборка через **Build Dream Cast TV APK** запускается только из develop.

## Сборки

- **software AV1** — для old ATV и устройств без аппаратной поддержки AV1. Для old ATV используйте 720p.
- **hardware AV1** — для устройств с аппаратной поддержкой AV1.

Установите один вариант. К APK приложены контрольные суммы SHA-256.

## Статус проверки поиска

На прежнем APK подтверждена потеря фокуса нативного поля. Новый код прошёл
автоматические тесты и компиляцию Kotlin, но ещё требует проверки нового APK
на old ATV: открытие клавиатуры, стрелки, OK, Back и повторное открытие поиска.
